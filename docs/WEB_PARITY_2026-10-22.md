## 一致性规则

- 历史只认新的文本 `content` 与后端 `segments`；不新增旧格式回退、客户端命令分流或按时间重排。
  同轮多条助手输出和外发消息按服务端顺序保留，使用归档 `id` 拼接更早回合。
- `final` 只停止对应气泡的流式效果。只有当前 `request_id` 的 HTTP/WS 终态可结束发送；
  重复回执只处理一次，迟到增量不重新打开已完成请求，其他客户端/后台回合不解除当前请求。
- 网络错误显示“结果未确认”，不自动重发；仍是当前请求时允许后续真实终态确认结果。
  保存失败保留可见的部分输出。命令反馈与附件恢复在 HTTP、WS 和切页之间保持一次处理。
- 保留共享草稿、上传回调、历史请求代次/修订保护及阅读位置保护。加载更早记录复用已有行，
  按归档 ID 前插并恢复可见锚点；普通刷新在阅读旧记录时延后替换。
- 配置使用后端 revision 防止覆盖并发更改；修改会使旧预览失效，受保护字段不可编辑。
  主机密钥只显示配置状态，客户端不读取或写入密钥值。新角色明确从空工具列表开始。
- 下载只在点击后请求，携带 Bearer 与设备 Cookie；流式落入临时文件，完整成功后才交给系统保存。
  HTTP 错误不会被存成附件，临时文件与句柄在成功、失败和取消时释放。
- 媒体播放同样携带请求头，不把 token 放进 URL；离开媒体组件释放播放器。
- 所有新增轮询与异步页面读取都受页面生命周期/请求代次保护。

## 2026-11-06 增量适配

核对远程 `main` 的 `5f647fc`；本地 Tentacle 将它与鸿蒙手机能力合并为 `9abbefe`，未推送或部署。

- 聊天发送按钮在回合运行期间用于停止；停止中、保存中防重复操作，仅原回合终态解锁发送。中断正文保留原文，历史与实时卡片显示“已中断”。
- WebSocket 连接、重连及应用回前台使用 `/api/chat/sync`。恢复归档与在途展示后，只处理相同进程且序号超出快照边界的事件；迟到快照、旧连接、旧停止回执均不能覆盖新状态。
- 网络失败保留结果未确认的正文，不重发输入或工具。缺少同步接口的旧后端回退历史刷新；WebSocket 暂不可用时仍可用 HTTP 恢复，并在在途回合存在时继续同步。
- 恢复保持草稿、附件、历史行标识、展开状态和手动阅读锚点；加载更早历史后的窗口大小也用于后续快照。
- Google Vertex 连接的创建、编辑支持 `credentials_env` 与 `gcs_base_url`，继续遵循后端 revision 校验、预览与保存流程，客户端不读取凭据文件。

新增隔离检查位于 `tests/check-chat-recovery.cjs`，使用合成历史、回合和模拟 HTTP。

核对 `tentacle` 提交 `be39c3b` 与迁移文档 `docs/HARMONY_PLUGIN_MIGRATION.md`，采用直接切换新架构策略，不保留旧路径与旧载荷兼容：

- 聊天工具调用卡片 `ToolCallItemView` 保留完整限定名（如 `p_harmony__phone_alarm`），同时通过 `parseToolSourceBadge` 展示可读来源角标（`插件 · <id>` / `MCP · <id>`）。
- 新增独立页面「插件扩展」（`PluginsPage`），对齐 WebUI `/plugins`：本地插件审核/启停/配置表单/禁用工具/权限与环境变量展示、`.env` 密钥只写录入弹窗、MCP 服务（`stdio` / `streamable_http`）增删改与立即重连、以及触发应用重启。
